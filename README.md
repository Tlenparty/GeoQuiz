# GeoQuiz

A minimal Android quiz app: the screen shows a question and two buttons,
"True" / "False" (originally «Правда» / «Ложь»); tapping one shows a toast with the result.

Written in Kotlin (AppCompat, `findViewById`), with a single screen, `MainActivity`.

## Build

Requires JDK 11–17 and Android SDK 30.

```bash
./gradlew assembleDebug
```
