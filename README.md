# GeoQuiz

Минимальное Android-приложение-викторина: на экране вопрос и две кнопки
«Правда» / «Ложь», по нажатию показывается тост с результатом.

Написано на Kotlin (AppCompat, `findViewById`), один экран — `MainActivity`.

## Сборка

Требуется JDK 11–17 и Android SDK 30.

```bash
./gradlew assembleDebug
```
